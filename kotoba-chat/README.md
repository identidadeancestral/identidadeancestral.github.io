# Kotoba — Japonês em imagens

Chat visual com cadastro, convites, grupos e cenas animadas para aprender japonês.

Aplicativo: https://kotoba-chat-identidadeancestral.aaaaasssdd.chatgpt.site

O acesso ao aplicativo ainda está restrito ao proprietário enquanto aguarda a autorização específica para torná-lo público.

Esta pasta contém o código completo. A autenticação usa a conta ChatGPT e os dados são persistidos em Cloudflare D1 através do Sites.

Para trabalhar localmente: entre nesta pasta, execute `chmod +x scripts/*.sh`, `npm ci`, `npm run build`. Testes: `node --test tests/chat-permissions.test.mjs`.

As cenas usam figuras emoji e estruturas de frase selecionadas. Texto livre não é traduzido automaticamente. O histórico se atualiza aproximadamente a cada 5 segundos.
